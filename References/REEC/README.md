## 证据与版权

出版社正文、摘要和Crossref元数据分别标记；卡片中的“审读判断”“迁移提案”是我们的分析，不是作者结论。只公开原创笔记与书目，未上传PDF、截图、原图、平台成交行、账户资料或导师反馈。论文可读不等于许可再分发。

## 与现有项目的关系

本研究主问题仍是拆除重建对周边既有住宅价格的动态影响。视觉模型测量环境与暴露；预测模型评价样本外增量；事件研究评价价格路径。三类证据不可互相替代。现有片区代理结果不是木头龙项目ATT。
