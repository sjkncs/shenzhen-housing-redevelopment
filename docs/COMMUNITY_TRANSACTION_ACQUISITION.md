# 周边既有住宅成交价格：来源核查与接收规格

本轮重点回到木头龙长期价格路径，不继续用行政区成交套数替代住宅价格。当前已有的平台真实成交CSV止于2024-04-25；尚未取得该日期后的新小区级成交记录，不把本文件标成已完成采集。

## 优先申请/接收的数据

第一优先为罗湖木头龙周边既有住宅及相应比较样本，保留原研究的2017年以来历史序列；先补2024-04-26至最新可供日期。若数据提供者可以提供重叠期，应同时取得2024年前若干月便于核对字段、价格定义、单位与平台覆盖变化。最新可得日期不是事先承诺的完整月份。

按基期小区身份筛选而非只接受更新后新建房。项目内部新建房、回迁房、公租房和商务公寓单独标识，不自动混入周边普通商品住宅。20个道路地址候选不是已核定空间范围；正式项目归属仍需可靠边界和住宅位置。

| 字段 | 接收要求 | 缺失后的处理 |
| --- | --- | --- |
| 来源交易ID | 来源内稳定，重叠期可识别重复 | 不用日期价格面积拼出永久房屋身份 |
| 成交/网签/登记日期 | 指明日期含义；不以采集日代替 | 不进入动态事件时间比较 |
| 成交总价、单价 | 明确币种及单位，并注明不是挂牌/参考价 | 不伪造价格或以总量指数回填 |
| 建筑面积 | 平方米及测量口径 | 不能核对总价—单价，另记录不可用性 |
| 稳定小区ID及原名 | 提供来源编码与改名/分期关系 | 名称只作为候选，不做自动身份认证 |
| 建筑/楼栋线索 | 如可合法提供，使用非个人编码或用途资料 | 建成年代不能自动当楼栋或分期 |
| 行政区和住宅用途、交易权属 | 住宅/商业、公租/商品、回迁等分开 | 不默认都是普通商品住宅 |
| 面积、房龄、楼层、电梯等属性 | 记录原值和缺失，说明旧新源是否同定义 | 不直接重用旧模型缺失规则而不评估选择变化 |
| 小区/建筑位置及坐标说明 | 标注经纬度轴序、投影、地图偏移、精度来源 | 不能计算正式红线距离 |
| 来源与权限 | 原始文件哈希、提取日期、使用/分享条件 | 不默认下载权等于公开再分发权 |

无需姓名、电话、身份证、个人权属名单或完整房号。可接受依法授权的非个人稳定标识，研究输出只报告必要统计。

## 新源接入顺序

先保存原文件与来源说明，校验日期、字段及权限；再检查跨来源稳定ID、重叠期间价格与属性定义、重复记录及覆盖变化。新来源不覆盖旧CSV，也不直接拼接为同一个已封存样本。

确认是实际成交价格并有可比较住宅身份后，分别检查季度成交支持和2024首批回迁后的观察窗口。若只能取得挂牌价、参考价或区月指数，单列为另一估计对象，不继续声称已经补齐长期成交价格DID。

## 向现有数据提供者的询问草稿

我们已有深圳平台二手住宅成交资料，最晚成交日2024年4月25日。拟研究木头龙拆除重建对周边既有住宅价格的动态影响，请问是否可依法提供2024年4月26日之后至最新可得日的同口径历史成交增量，以及重叠期样例、稳定小区/交易编码、价格定义、坐标说明和非商业科研使用条件？不需要任何业主身份或联系方式。若数据为挂牌、估价或指导参考价，请明确标注，便于区分研究对象。

本草稿未发送、未授权远程订阅或购买。当前登记/交付日期和空间归属缺口也没有因这份接收规格而解决。
