# 研究设计

拆除重建可能通过长期配套收益、交通改善与新增可替代供给影响周边既有住宅价格。公告及实施概率先改变预期，配套开放与住宅交付再改变兑现程度。施工负担是阶段性成本，但其成交价格影响不可先验断言为零或必然负值。租金机制需要独立租赁资料，不能用成交价格代替检验。

正式研究先限定木头龙及一个可核验的周边生活圈。住宅必须在事件前存在，项目内部被拆住宅、新建房和周边既有住宅应分别识别。项目边界必须区分整体拆除范围、零星征收范围和新增供地宗地。规划纳入、签约、拆除、施工、交付及配套开放均保留来源，不能互相替代日期。

当前片区代理模型为：

$$\log P_{it}=\delta(C_i\times D_t)+X_{it}'\gamma+\alpha_i+\lambda_t+\varepsilon_{it}.$$

其中$C_i$表示来源中的翠竹商圈，$D_t$表示2020Q2及之后，$\alpha_i$为小区固定效应，$\lambda_t$为季度固定效应。主回归剔除2020Q1过渡季度。该处理强度是商圈标签，不是住宅到木头龙红线的距离。

动态模型以季度虚拟变量与$C_i$交互，参照2019Q4，允许观察事件前后差异。实际检验显示显著事件前变化，因此当前系数必须结合预期、片区原有趋势和同期冲击解释。小区聚类不能解决只有一个处理商圈的共同冲击问题。

下一步按基期住宅和项目边界构建处理/比较样本，再核对事件前趋势、比较组污染和交易样本构成。长期配套与供给机制、空间异质性以及图学习暴露测度，只在相关指标和识别条件充分时推进，不提前列为已经完成的创新。
