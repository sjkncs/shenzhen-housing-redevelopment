# 数据访问与公开范围

| 材料 | 公开版 | 私有研究档案 |
| --- | --- | --- |
| 全市交易覆盖与行政区汇总 | 公开 | 同步保留 |
| 罗湖模型级结果与事件研究图 | 公开 | 完整结果保留 |
| 交易明细、分析样本 | 不公开 | 上传私有仓库 |
| POI明细、住宅候选连接与GPKG | 不公开 | 上传私有仓库 |
| 全市POI、建筑原始压缩包 | 不公开 | 私有数据发布附件 |
| 开题报告、PPT、任务书 | 不公开 | 私有仓库原样存档 |

公开版本不含住宅逐条地址、坐标、交易详情URL、学号或导师反馈录音转写。原始平台资料的使用权和再分发权不是同一回事；仅在取得明确公开授权并完成个人信息处理后，才考虑公共下载。

私有档案由仓库所有者管理，访问需要明确授权与邀请。可通过GitHub Issue讨论代码或提出数据访问需求，但请勿贴出原始记录、认证信息或非公开文件。

数据暂未设定对外开放许可。不得将聚合统计或来源文件的可获得性当作整套数据已开放的证明。
