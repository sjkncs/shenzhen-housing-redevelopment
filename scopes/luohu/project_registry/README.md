# 六个指定候选项目

这是用户指定的候选清单，不是“罗湖仅有六个”的全区统计。项目模式、阶段与观测期须逐项核定，尤其自主原拆原建与市场化更新不可直接视为同质处理。

| 项目 | 当前整理用途 | 官方线索与待核事项 |
| --- | --- | --- |
| 木头龙 | 优先主案例 | 本仓库存档拆除边界、一期许可与布局；仍需配准、住宅归属和分期事件核对 |
| 金钻豪园 | 潜在比较案例 | [2025年权益资料提交通知](https://www.szlh.gov.cn/lhczjdbsc/gkmlpt/content/12/12137/post_12137298.html)；盘活、主体确认与实际施工应分别核对 |
| 三九花园 | 项目进展候选 | [2025年意愿征集通知](https://www.szlh.gov.cn/lhqshjdbsc/gkmlpt/content/12/12421/post_12421560.html)；用户所述批次、面积和实际开工仍需对应公告 |
| 广场北片区 | 项目进展候选 | [官方意愿征集结果](https://www.szlh.gov.cn/lhgyjdbsc/gkmlpt/content/12/12761/post_12761613.html)；意愿同意率不等于完成拆除或开工 |
| 红岗花园 | 自主更新比较线索 | [清水河2026上半年工作总结](https://www.sz.gov.cn/szzt2010/wgkzl/jggk/lsqkgk/content/post_12890393.html)；首开区方案与实际实施须区分 |
| 深圳市第一幼儿园宿舍楼 | 自主危房原拆原建案例 | [2026年规划许可公示](https://www.sz.gov.cn/cn/xxgk/zfxxgj/tzgg/content/post_12781548.html)；与市场化旧改的制度及供给机制不同 |

本地候选状态记录用于后续核查，不将尚未获取的项目红线填成推测多边形，也不因有项目名称就自动生成空间处理变量。

2026年10月13日新增[木头龙2019年原坐标网转录](mutoulong/native_grid_2019/README.md)：45个界址点、两个未地理配准的工作环及检查图。图件对象是零星征收范围，坐标系和整体拆除范围等价性尚未确认；不得直接据此计算处理住宅距离。

同日新增[官方图纸像素空间比对](mutoulong/image_comparison_2019/README.md)：主环与整体拆除图有较强形态对应，三角地不在该图蓝色主边界内。6点拟合、6点留出检查，不构成官方坐标转换或地理配准。

同日完成[官方坐标依据检索](mutoulong/coordinate_evidence_followup.md)与[边界成果申请草稿](mutoulong/coordinate_records_request.md)。已取回三份官方材料，分别记录原件与下载失败状态；申请尚未发送，项目坐标系及转换成果仍未确认。
