# 拆除重建项目扩展：用户AI线索的官方复核

本清单整理用户提供的罗湖到全深圳项目线索，共17个项目/分期候选，不是全市完整名单，也不是已核定17个处理项目。原旧住宅、城中村、棚改和自主危房原拆原建分别登记。最终同质样本仍优先选原旧住宅拆除重建，不把更新后的居住功能当作原址就是旧住宅的证据。

## 本轮可确认的重点

三九花园官方2026年第一批计划、计划表和拟拆除图均已取得原件。计划载41,370平方米，拟更新方向为居住等功能，公共利益用地大于3,000平方米且不小于15%，有效期2026-01-09至2028-01-08。申报主体是清水河街道办，不能等同实施主体。附件明示规划编制与实施主体确认后方可开发建设；拟拆除范围不是已经验收配准的红线。

木头龙2025年政府报告回顾2024工作时已记载首批业主收房回迁。这是一段年度区间的实际事件证据，不确定具体回迁日或所有分期交付，不能再概括整个项目只有施工状态。用户AI的2029全面回迁缺少本轮核定依据，应保留为未核实说法，不回填事件模型。

第一幼儿园宿舍楼区住建2026上半年总结记载5月23日开工、已拆除清运、推进主体施工，预计年底竣工验收。预期竣工与实际回迁不同；官方域名转载媒体的2027年初回迁说法仍为预期，不是已发生的日期。

螺岭片区在同一总结中为全面启动签约，属于城中村改造；湖贝A2与A3必须分开。华富北01-01取得规划许可、庆宜华苑A006-0942取得用地批复，均不直接证明主体施工或未来回迁。庆宜的6,542.5平方米是该供地宗地面积，不是原整体拆除范围。

## 对长周期研究的影响

当前成交来源最晚到2024年4月25日，不能研究2025—2026新实施项目的事后成交，也不能覆盖木头龙报告所述回迁后的完整长期路径。没有后续交易时，新计划项目只用于名录、阶段资料或预期研究候选，不作为已有施工/交付处理效应。

现有候选六个项目继续保留，这17个补充线索不替换它们，也不宣布所有未来回迁年份得到确认。无可靠来源的2030—2033等预计日期不进入日期字段。旧住宅类优先核查木头龙、金钻、三九、鹤塘、南苑；棚改和自主更新分制度单列，城中村另设扩展组。
