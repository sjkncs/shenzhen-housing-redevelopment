# 木头龙2019年零星征收图：坐标转录与原坐标网检查

本轮从已存档官方原图转录J1—J45，并用高分辨率坐标表截图逐行再次目视比对。两次阅读为同一核查者完成，不是独立双人转录。

来源：[官方零星房屋征收范围图](https://www.szlh.gov.cn/lhqwbgs/img/1/1142/1142605/7649730.jpg)。源文件SHA-256及CSV哈希见`audit.json`。未修改原图或先前成果。

按蓝色轮廓目视分成J1—J32和J33—J45两个闭合环；`main`、`triangle`是本轮工作标签，不是官方地块编号。45点编号连续、无重复坐标；两个多边形有效、没有自交、彼此不相交。WKT仅记录原图数值，没有附加EPSG。

主环原坐标网面积为77,033.595平方原单位，另一环6,211.820平方原单位。主环数值接近此前整体拆除公告77,026.8平方米，差约6.795；但单位、范围等价性和版本仍未核实。不能用面积接近证明两幅图边界相同，也不能用面积反向调整坐标。

预览图把原表X放横轴、Y放纵轴，只显示坐标网拓扑，不代表现实地图朝向。原图绘图轴序、坐标系、单位及转换参数未确认；没有转换为WGS84、GCJ02或CGCS2000，没有计算住宅距离，也没有新增DID结果。

下一步可将该轮廓与整体拆除原图进行独立图形比对，并核对官方旧新宗地关系。最终仍需坐标依据、足够分布的同名控制点和独立检查点，才能生成与住宅定位相容的地理边界。不能把J1—J45直接用作经纬度或整项目处理边界。

文件：`coordinates.csv`为45点转录；`source_grid_rings.csv`为两个未配准环的WKT和拓扑统计；`source_grid_preview.png`为检查图；`coordinate_table_crop.png`为原图核对截取；`audit.json`为来源、校验和未决状态。
