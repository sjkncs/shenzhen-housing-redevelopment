# 首次登记状态与楼栋范围核查

本轮按H218-0049、御龙华府、御龙天地及首次登记公告检索，新增一份2025年8月官方答复；没有取得可确认逐楼栋的首次登记公告附件，因此不填回迁栋数或登记栋号。

[2025-08-19答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3230970&via=pc)称“御龙天地”尚未办理国有建设用地使用权登记及房屋所有权首次登记。该答复未给宗地与楼栋范围，是答复时状态证据，不是建筑未交付或无人入住的证明。

[2025-11-07答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3289061&via=pc)明确御龙华府位于H218-0049，2025年9月办理首次登记，具备转移登记条件。两次答复可作为状态变化线索，但8月答复没有同等精度的宗地范围，不推定两者覆盖所有相同楼栋。只保留官方给出的9月区间，不根据答复差距计算审批耗时。

咨询者所说“网站仅显示1栋商品房”是提问内容，不是部门确认结果。本仓库不把它写成正式楼栋清单。登记与交付、回迁、设施开放必须分开；2024年首批回迁和2025年首次登记并不要求发生在同一日，也不凭这两条资料推断法律关系或违规情况。

公开表[registration_status_evidence.csv](registration_status_evidence.csv)只摘取部门状态判断、项目名、宗地键、来源和日期精度，不转载留言者个人经历。阅读来源为官方页面，尚未新增原页本地归档记录。

下一项需要的资料是已公开首次登记公告的公告号、登记日期及可公开楼栋范围，或相关主管部门的范围说明。不要索取个人权利人清单，不用预售计划或意向登记人名册替代不动产首次登记成果。现有成交截止2024-04-25，不能估计2025登记后的成交效应；本轮未修改处理组或价格模型。
