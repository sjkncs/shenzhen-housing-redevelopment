# 木头龙边界与坐标依据资料申请草稿

状态：2026-10-13准备，尚未提交、尚未发送。以下正文供申请人按实际身份和主管部门办理渠道填写使用；不表示已取得授权、部门承诺或完整坐标成果。

## 申请正文

本人拟开展木头龙拆除重建项目对周边既有住宅价格影响的毕业论文研究，需准确识别历史拆除边界及周边既有住宅。现申请提供下列已制作、已保存且可公开的资料，或指明资料保管单位及获取渠道：

1. 罗湖区翠竹街道爱国路木头龙小区城市更新单元整体拆除范围的批准版本边界成果。公开图件为《拆除与建设用地范围图》，相关公告面积口径为77,026.8平方米。请优先提供已有CGCS2000坐标成果或带完整坐标说明的SHP+PRJ、GPKG、DWG、界址点CSV；如没有电子成果，请提供已有坐标表、图纸坐标说明或档案索引。请保留成果名称、批准文号、版本及测绘日期、坐标系、单位、轴序和投影说明。

2. 罗府函〔2019〕293号相关《木头龙片区零星房屋征收范围图》J1—J45的原始点位表及坐标依据。请提供已有资料中该范围与整体拆除范围、文锦中路旁三角地的对应说明。研究不得把征收范围或三角地当然视为整个更新项目拆除范围；若需分别向其他保管单位申请，请告知名称及材料标识。

3. 如已有上述历史边界向CGCS2000转换的批准成果，请提供允许公开的转换后边界、点位表及成果精度或使用范围说明。申请不要求公开受管理的转换参数，也不要求机关为申请人重新测绘、重新计算或制作统计。

4. 如整体拆除范围资料不足以确定空间依据，请协助检索01-02地块H218-0049（宗地编码440303005005GB00044）建设用地规划许可证/规划要点函HG-2020-0001的已有附图及坐标说明，以及建设工程规划许可证HG-2020-0013所引用的《开工验线报告》深测工[验]-B2-202000804、2020年11月19日的可公开成果或档案索引。请将建设宗地范围与历史拆除范围分别说明，不以建设宗地替代拆除边界。

5. 如涉及分期或范围变更，请提供已有的01-01/H218-0048、01-02/H218-0049等宗地与旧宗地的对应关系及有效版本日期。已知旧宗地检索线索包括预H218-0109、H218-0040、H218-0009、H218-0010、H218-0011。这些编号仅为检索线索，不是申请人已确认的完整空间对应。

本申请不涉及个人权利人名单、身份证号码或联系方式，不要求公开测绘控制网参数等不宜公开信息。若部分内容不宜公开，请说明可分离公开的成果、替代资料或合法科研服务办理渠道。

申请人姓名、联系方式、身份证明、学校及科研用途说明，请在正式受理渠道按要求另行填写；本公开草稿不包含个人资料。

## 服务咨询补充稿

根据深圳市规划和自然资源局2025年8月7日关于独立坐标转国家2000坐标的答复，请咨询学校毕业论文研究能否通过“连续运行卫星定位服务系统服务使用”（选择深圳市）申请已有边界转换成果或坐标转换服务，需何种主体资格、介绍信、授权材料、费用及交付精度说明。我们请求合法服务或可公开成果，不要求提供转换参数。当前未办理申请，亦未确认学校或个人符合服务资格。
