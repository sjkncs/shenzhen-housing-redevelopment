# 木头龙项目名称与宗地连接

本轮取得官方网页层面的直接连接，更新此前“御龙华府与宗地尚未连接”的状态；不是取得地理边界或证明各分期整体等价。

## 明确连接

[规自局2025年11月7日办证答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3289061&via=pc)明确益田御龙华府位于H218-0049，2025年9月已办理不动产首次登记。仅引用部门答复，不用咨询者留言中对回迁楼栋的描述认证全部楼栋。月份登记不是交付日，也不能给此前施工或回迁补日期。

[2022木头龙01-02建设规划许可证](https://www.szlh.gov.cn/attachment/1/1218/1218402/10259049.pdf)明确同一H218-0049及宗地编码。因此可按宗地将木头龙01-02与御龙华府连接；不把01-01/H218-0048及完整历史拆除范围扩展到这个键。

[官方库存表第4页](https://pnr.sz.gov.cn/attachment/1/1362/1362393/10871175.pdf)在H218-0049和H218-0050都使用益田御龙天地名称，前者普通商品住房，后者公租房。这是名称一对多宗地的证据；表内约定开竣工日期仍是合同约定，不代替实际事件。

## 服务线索的归并范围

此前御龙华府公共设施登记可归入与H218-0049名称关联的资料链，但公告没有逐设施宗地编码，具体设施—楼栋—宗地仍需核实。不能据同名把每处幼儿园、体育中心和泵站全部空间归属为已接受。

[2026年2月4日社区工作站信息](https://www.szlh.gov.cn/dzfwdt/zfjg/sqgzz/content/post_12631324.html)列木头龙社区工作站地址为爱国路1009号御龙华府三栋三楼。它支持该日页面列有办公地点与工作时间，不确定首次搬入或正式开放日期，不与2026工作计划的搬迁安排机械合成新事件。
