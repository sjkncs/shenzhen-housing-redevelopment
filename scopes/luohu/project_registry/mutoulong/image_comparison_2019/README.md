# 木头龙两幅官方范围图：像素空间轮廓比对

2026-10-13完成原坐标轮廓与整体拆除原图的叠加。原始资料分别是2019年零星房屋征收范围图J1—J45坐标表，及[整体拆除与建设用地范围图](https://www.szlh.gov.cn/lhqzfhjsj/gkmlpt/content/5/5919/post_5919622.html)。本轮没有执行桌面转换程序，没有转换到经纬度。

## 方法

整体拆除原图4967×3508，阅读参考图固定为1888×1333。按可见轮廓角点目视对应，预先区分6个拟合点和6个留出点；坐标只指向参考图像素。用6个拟合点估计原坐标网到像素的仿射变换，再检查未参与拟合的6点。原点中心化避免大坐标数值病态；完整参数与源哈希见`comparison.json`。

目视选点和检查点均由同一核查者完成；目标图没有J点官方标注，匹配依据是轮廓角点形态，不是有来源的测量控制点。不能据此声称独立测绘验证，未设事后通过门槛。

## 观察结果

拟合RMSE为1.462个参考图像素，留出RMSE为3.074像素，留出最大误差4.358像素。叠加图显示主环J1—J32与整体拆除蓝色主边界有较强形态对应；J33—J45对应文锦中路旁三角地，不在该图蓝色主边界内。该发现支持把两组点分开，反对将45点全部连成一个处理红线。

本轮只形成主环的待确认范围对应线索，不认定官方范围完全等价。像素误差不能直接写成地理误差；坐标系、轴序、单位与版本关系仍待确认。不得将图像变换参数用于住宅定位、GIS距离分档或项目DID。
