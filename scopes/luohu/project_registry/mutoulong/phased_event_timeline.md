# 木头龙分期事件时间线

本轮把行政许可、活动、实际阶段报告和配套计划分开登记。[事件CSV](phased_event_timeline.csv)包含九条有官方来源的线索。原件归档状态以既有来源清单为准；新增网页是本轮官方检索线索，未宣称所有新页面都已本地下载。条目不是九次独立处理，不直接进入回归。

## 施工节点

官方大事记记载2020年3月4日在木头龙现场举行12个重大项目集中开工活动。另有2020年上半年执行情况报告记载木头龙正式开工。这两条相互补充，但活动现场日期不能直接证明每个地块实际施工日。2020年3月5日为用地批复公告发布，2020年9月为01-02一期规划许可月份，2020年11月19日为被许可证引用的验线记录，四者不可互换。

原片区试算使用2020Q2作为完整事后季度，并剔除2020Q1。这仍是现有诊断口径，不因新时间线自动获得项目识别有效性；上半年报告本身也不能精确确定施工季度。正式模型需按实际施工和分期核定。

## 回迁与配套

政府报告回顾2024年记载首批收房回迁，本轮仍未找到足以核定具体日期及楼栋的直接原件，因此保留年度区间，不填写年中日期，也不从网络预测倒推2029全面回迁。

2026年工作计划出现社区服务场所向益田御龙天地3栋3楼搬迁安排；教育局2026年5月公示御荣分园改造建议书，拟提供约360个学位。这些是安排和拟建设容量，不能作为已开放服务、实际可达性改善或回迁后机制已经验证的证据。

## 对数据窗口的约束

全市成交源截至2024-04-25，原片区回归窗口止于2023年底。2024年度首次回迁未定日，不能确认现有源是否含回迁后交易；现有回归更不包含2024交付后的路径。2026配套计划完全超出当前成交源，不能用现有数据估计其开放后价格效应。

下一份应找的是首批回迁的具体交付/验收文件、楼栋或分期名单及实际设施开放记录，不是继续补预计回迁年份。住宅身份和可靠红线仍需另行核验，时间证据不能代替空间归属。
