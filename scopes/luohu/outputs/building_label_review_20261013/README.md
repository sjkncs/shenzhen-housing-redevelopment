# 建成年代多值与官方楼栋线索

本轮取回并本地归档三份官方页面，只公开楼栋线索、来源URL及SHA-256，不复制原页全部个人联系人。没有得到竣工验收或权籍成果，因此没有拆分原分析样本。

| 候选 | 原交易年代情况 | 官方页面可确认的线索 | 不能推出的结论 |
| --- | --- | --- | --- |
| 泰宁花园 | 1995与1996均在前后成交出现 | 2019年检查公示出现裙楼A、B、C栋等 | 没有年份—楼栋对应，不能分为两个建设队列 |
| 华丽西村 | 前段9笔出现7个年代，含2009；后段无成交 | 2026年托育评估出现华丽路1021号、4号大厦 | 不能确认2009记录属于该大厦，或认定早期住宅更新 |
| 京基东方华都 | 118笔中117笔标2005，1笔标2006 | 2021年检查记录出现文锦中路2063号东方华都大厦四楼 | 不能把单笔2006自动纠正为2005或认定独立分期 |

这些是名称/楼栋线索，不是住宅身份或官方年代认证。尤其“裙楼酒店、公共场所、托育地址”不能替代住宅部分用途。应保留平台原年份，待取得楼栋编号与权籍/竣工依据再解释差异。

公开[证据表](building_label_evidence.csv)与[摘要](summary.json)记录三份成功归档、零个年代对应接受、未拆样本。华丽西村16栋另有官方PDF搜索线索，但本轮没有归档检查该PDF，不将它计入成功来源。

复现脚本见[collect_building_identity_evidence.py](../../scripts/collect_building_identity_evidence.py)。需要联网并指定本地原页存储与新输出目录，下载失败明确记录；原成交与封存回归不变。
