# 木头龙相关道路地址线索与成交支持

核查日期：2026-10-13。本轮在坐标依据待取得期间，先检查住宅身份线索和可观测成交支持，不估计价格效应、不赋予项目处理状态。

## 输入与方法

输入为已封存的621小区覆盖表、318组严格名称POI连接、17组地址限定名补充线索及2017—2023年11,231条片区分析样本。原始文件哈希记录在[summary.json](summary.json)。按POI地址中是否含华丽路、爱国路、文锦中路筛选名称连接线索，保留POIID和匹配规则；不按经纬度距离筛选，不把道路地址代替生活圈边界。

统计窗口沿用现有诊断：前段2017Q1—2019Q4，过渡2020Q1，后段2020Q2—2023Q4。这是观测支持分段，不意味着之前没有更新预期，亦不意味着2020Q2是每个住宅唯一有效处理时间。施工、公告、拆除与规划时间仍须分别核定。

## 实际结果

| 指标 | 数量 |
| --- | --- |
| 全部罗湖覆盖小区 | 621 |
| 三条道路地址线索小区 | 20 |
| 地址线索小区窗口内成交 | 366 |
| 前段与后段均有成交的小区 | 13 |
| 地址线索小区窗口内无成交 | 0 |

季度表显示2022Q1、Q2、Q3各只有2笔成交；2021Q3和2023Q2各3笔。京基东方华都在该线索集合中有118笔，占366笔约32.24%。这提示应核查聚合结果是否由少数小区或时段驱动；成交缺失不能写成“价格不变”或“没有政策作用”。后续正式项目分析应报告各距离档和比较组的覆盖，不机械补齐缺失成交。

三条道路较长，覆盖集合可能包括不在项目影响范围内的住宅；更新后新建小区、分期、门点以及同名位置仍需核查。因此不将20个线索小区或13个有双段成交的小区自动定义为处理组/可比组，也不按统计支持好坏选择显著结果。

## 文件

- [all_621_community_support.csv](all_621_community_support.csv)：保留全部621个小区，包括不在回归窗口内成交的小区，记录两段成交、过渡季度及缺失季度数量。
- [road_address_leads_support.csv](road_address_leads_support.csv)：20条道路地址线索及对应支持，所有住宅身份、坐标和项目处理状态仍为未接受。
- [road_leads_quarter_support.csv](road_leads_quarter_support.csv)：该线索集合的季度成交数量与小区数量，不是价格效应表。

复现脚本为[候选支持核查](../../scripts/audit_mutoulong_candidate_support.py)。输入来自公开Release解压后的相应CSV，参数显式传入；脚本拒绝覆盖已有输出目录并检查来源小区、季度窗口与重复交易。

下一步优先核定20个线索的住宅主体、基期存在状态和官方地址，再在获得项目坐标依据后计算边界距离。身份与距离未核定之前，不新增正式项目DID或ATT。
