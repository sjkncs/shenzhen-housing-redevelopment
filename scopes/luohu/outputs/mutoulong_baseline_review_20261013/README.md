# 20个地址线索的基期证据核查

平台记载显示17个小区在2020年前已有成交，另3个只有2020年前建成年代字段而无2020年前成交。7个小区有多个建成年代值；这可能涉及分期、楼栋或平台填报差异，不能直接判定为错误。

本轮没有接受官方住宅身份、竣工年份或处理归属。2020年是观测分段参考，不是确认无预期的基期。后续搜索找到京基东方华都文锦中路2063号、华丽花园华丽路1041号等官方地址线索，尚未完成本地归档和逐小区权籍核定。

数据来自同一封存交易文件，不把交易年代与建成年代当作两套独立证明。没有剔除原分析小区或新增回归结果。详情见baseline_evidence.csv与summary.json，复现代码见当前罗湖scripts目录。
