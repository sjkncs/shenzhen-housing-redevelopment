# 罗湖建筑轮廓候选：供应全市包的空间筛选

本轮从用户已提供的深圳建筑包，而非新官方罗湖建筑集，提取候选。建筑源144,781条，声明EPSG:4326；区界来源GData2，10个行政区、声明EPSG:3857，其中一条标为罗湖区。区界投影到建筑声明CRS后，仅对有效非空源几何做相交筛选，既没有互联网地图纠偏，也没有接受源与区界的独立测量位置。

| 结果 | 条数 |
| --- | ---: |
| 与供应罗湖边界相交的有效候选 | 12,837 |
| 完全位于边界内 | 12,703 |
| 跨越或接触边界 | 134 |
| 全市源无效或空几何，未修复 | 564 |

无效源对象的几何包络筛选未落入罗湖区界包络，本项只是包络诊断，不证明源在地理上全面覆盖罗湖。界内、跨界标签依赖声明坐标口径，靠近边界的对象尤其需独立核验。

建筑字段只有Id、Floor和geometry，没有住宅用途、建筑年代或楼栋名称。原Id在候选内不唯一，本轮candidate_id按源行序号生成，只保证该版本可追溯，不跨版本充当官方楼栋ID。Floor是源报告属性，不认证实际层数或高度。

**这不是完整官方罗湖建筑数据集，也不是已接受的住宅基期底图。** 采集年份、底层地图口径、用途和历史存在仍待核定，没有连接成交记录或计算木头龙距离。原SHP组件哈希在summary.json，筛选完成后再次核对未改变；候选GPKG回读数量、唯一候选ID及几何有效性均通过。

原始全市建筑包已在此前数据Release；本次候选GPKG、属性表另在[建筑候选Release](https://github.com/sjkncs/shenzhen-housing-redevelopment/releases/tag/building-candidates-20261014)提供。原区界来源需GData2，不在既有全市建筑RAR中；不能称克隆后仅凭建筑RAR就可完整重建。

## 官方专题资料如何使用

环境影响类资料优先核对项目名、位置、审批日期和用途；住房情况类统计用作市场或人口背景；占用绿地、砍迁树木公告用作项目实施和环境事件线索。除非真实字段含逐栋几何与稳定标识，否则不能替代建筑轮廓，更不能从专题名称推定包含建成年代。

官方平台确有“建筑物数据”入口线索，见[平台字段搜索](https://opendata.sz.gov.cn/newsearch)，本轮未取得该目录的实际字段样例、下载条件或罗湖全量几何，不能写成官方建筑集已下载。用户列出的具体环评与住房主题尚未核定精确目录ID。

代码：[extract_luohu_building_candidates.py](../../scripts/extract_luohu_building_candidates.py)，显式传入全市建筑SHP、区界SHP和新输出目录。发布统计不包含面积或密度估计，避免未知底层坐标和历史时点对经济解释的混入。
