# 项目准备表与观察窗口

本表对17个补充项目线索，按本轮新登记的8条事件证据与全市交易来源截止2024-04-25比较。不是所有项目完整事件史，也不是正式样本资格验收。

## 当前结果

5个候选的已登记事件晚于截止日，现有文件没有这些事件之后的成交；10个候选本轮没有可核定具体区间。木头龙首批回迁只有2024年度区间，跨越成交截止，不能取年中日期伪造交付事件。鹤塘配建保障房2022年5月交付在全市来源时间覆盖内，但不是全项目回迁，且附近住宅支持尚未核实。

**上述结论只针对表内事件。** 木头龙已有2020年施工线索和片区试算，本表选择新增首批回迁记录，不意味着木头龙没有施工后价格观察。未来每个项目应维护多条分期事件，而不是用一个日期取代公告、施工、交付和设施开放。

## 下一步资料优先级

木头龙：优先确认主环坐标依据、2020施工的分期范围，以及2024首批回迁的具体日期和用途。鹤塘：优先核定旧住宅对象、拆除及施工日期、配建交付与回迁的区别，再检查南山附近成交。金钻与三九：按计划、主体确认、施工、停复工分阶段核定，不填预计2028/2032回迁作为实际事件。

原旧住宅优先准备，棚改、自主更新、城中村分别作为制度和对象不同的扩展组。计划更新为居住不说明原址为旧住宅；规划许可不等于已施工。当前没有已接受的项目空间处理样本，不能据此新跑正式项目ATT。

文件：[project_readiness.csv](project_readiness.csv)逐条列准备状态；[summary.json](summary.json)汇总数量。来源见[事件证据表](../../project_registry/expansion_review_20261013/event_evidence.csv)。脚本[build_project_readiness.py](../../scripts/build_project_readiness.py)只比较有来源的日期上下界，不补日、不设显著性筛选。
