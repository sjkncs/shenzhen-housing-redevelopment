# 20个候选的成交构成核查

输入为封存片区分析样本、公开原始成交CSV与20个地址线索的基期证据表。通过成交详情URL一对一取回楼层属性，原文件哈希核对一致。输出仅为分组统计，不包含逐条房源URL。

366笔成交分为前段202笔、2020Q1过渡19笔、后段145笔；13个小区前后均有观测。7个小区的平台建成年代多值不能直接归因为错误，也不能直接推定分期或楼栋。楼层高/中/低标签在本批次均可读取，但跨楼层总层数仍不可视为统一物理高度。

集浩花园中位面积从67.43㎡变为97.555㎡（前4笔、后8笔），华丽花园从88.50㎡变为100.325㎡（前17笔、后10笔），阳光绿地家园从51.39㎡变为41㎡（前15笔、后21笔）。样本很小，不能把这些差异当显著性结论或自动剔除依据。京基东方华都前后面积中位差约-0.65㎡，也不能据此保证所有属性构成稳定。

`reported_year_share_total_variation`为前后建成年代频率分布的总变差距离，0表示相同，1表示支持不重叠；不是年份误差或显著性检验。金盾花园与外贸大院虽为1，但前后分别只有2/1笔和1/1笔，不支持确认结构改变。无前后双段成交者不会填成0。

文件包括分时期构成、建成年代频率、楼层频率和前后面积/电梯/年代构成差异；价格中位数仅是原样本描述，不是更新效应。未更改原样本、处理标签或已封存回归。下一步需楼栋或权籍依据，必要时在明确的正式项目样本上做属性调整和构成敏感性分析。
