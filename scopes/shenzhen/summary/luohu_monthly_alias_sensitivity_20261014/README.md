# 罗湖月度行政区记录口径敏感性

比较现有隔离表（同日同用途标准区名冲突的两行均隔离）与相加诊断表（两种原区名的原始行都计入）。不覆盖现有表，不接受来源方尚未确认的合并含义。输入均为公开目录中的统计表，原源记录ID用于防止重复纳入。

| 月份 | 隔离口径已报告套数 | 相加口径已报告套数 | 差值 | 相对隔离口径差异 |
| --- | ---: | ---: | ---: | ---: |
| 2022-05 | 295 | 351 | 56 | 18.98% |
| 2022-06 | 287 | 355 | 68 | 23.69% |
| 2022-07 | 288 | 315 | 27 | 9.38% |

共18条冲突原行、9个住宅日组，加入后多151套、11,851.46平方米。变化只发生在上述三个月。隔离口径分别覆盖22、25、23日，相加口径分别覆盖25、29、25日；两者都不是完整日历月份，缺行没有补零。因此相对差异反映记录纳入与覆盖变化，不是同比/环比、市场增长或政策影响。

此前70个全市日期—用途对账组里相加全部吻合全市合计，为内部可加性证据。本轮只测量该假设对罗湖月度已报告量的影响，不声明来源官方已经确认分组含义，亦不恢复主口径为完整总量。

文件：luohu_monthly_alias_sensitivity.csv保存全部月份及缺月为空；affected_months.csv仅保存三个受影响月；summary.json记录输入哈希、差值和未接受状态。脚本[compare_luohu_monthly_aliases.py](../../scripts/compare_luohu_monthly_aliases.py)可用已公开CSV独立复现，无需交易价格、地图或平台appKey。

下一步应取得来源对带区后缀记录的含义说明；在使用月度量作背景前，报告两种口径和日覆盖，不能用它替代周边既有住宅成交价格数据。
